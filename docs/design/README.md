# Direction visuelle YFEN

La maquette interactive de départ est conservée sous [`yfen-mockup.html`](yfen-mockup.html). Son style dark fintech premium (fond nuit, vert menthe, bleu, violet, surfaces translucides, Inter et Space Grotesk) sert de base au frontend React.

Adaptations de périmètre :
- Le nom affiché est **YFEN — AI Business Control Tower**.
- Le parcours de virement simulé est retiré et remplacé par un centre d’actions illustratif, conformément au PRD.
- Les noms d’écrans sont rapprochés de la navigation du PRD : Mon portefeuille, Données, Détail source, Analyse, Actions, Paramètres & accès.
- Les montants et activités de cette page restent des données fictives. Elle n’est pas une preuve de connexion API ni une capture d’une session réelle.
